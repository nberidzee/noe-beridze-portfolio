## Publishing

This is a static HTML, CSS and JavaScript website. GitHub Pages serves the root of the main branch. A .nojekyll file keeps the source files unchanged.

Update content.js for project copy, resume.js for resume data, and app.js or style.css for presentation. Update Noe_Beridze_Gulf_Product_Owner_CV.pdf whenever the downloadable resume changes. Assets and links use relative paths so project pages work under the repository URL.
